#  Vivo Smartphone Landing Page

A modern and responsive smartphone brand landing page built using **HTML5** and **CSS3**. This project showcases a clean UI design inspired by premium smartphone brands, featuring a hero section, product showcase cards, responsive layout, and smooth animations.

##  Features

- Modern and clean design
- Responsive layout for mobile and desktop devices
- Fixed navigation header
- Hero section with call-to-action button
- Product showcase section
- Hover effects and smooth card animations
- Pure HTML & CSS (No frameworks required)

##  Responsive Design

The website is optimized for:

- Desktop
- Tablet
- Mobile Devices

When viewed on smaller screens:
- Navigation menu is hidden
- Hero section stacks vertically
- Images resize automatically

##  Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/vivo-landing-page.git
```

2. Open the project folder:

```bash
cd vivo-landing-page
```

3. Run the project by opening:

```bash
index.html
```

in your browser.
